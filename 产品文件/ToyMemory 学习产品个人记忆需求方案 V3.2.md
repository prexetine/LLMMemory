# ToyMemory 学习产品个人记忆需求方案 V3.2

## 一、项目背景

当前学习产品已经具备查词、翻译、报听写、生词本、背单词、专项测试、复习计划、教材同步听、英语听力专项、英语同步学、练口语、拍英语作文、数学同步学、全科讲题、国学/内容学习等能力。

这些功能已经产生大量与孩子学习相关的行为和结果信息，例如：

- 最近学习什么学科、使用什么学习功能；
- 什么时间进行学习；
- 主动选择、搜索、收藏了什么内容；
- 单词认识、模糊、不认识；
- 英文选义、中文选词、填空拼写结果；
- 报听写中用户主动标记的错误词；
- 生词本收录情况；
- 英语作文中的单词拼写检查结果；
- 单词及句子的发音评测结果；
- 发音准确度、流畅度、完整度、标准度及发音指导；
- 单词未学习、学习中、已掌握状态；
- 单词复习计划及后续复习。

当前核心问题不是缺少学习功能，而是：

> **这些分散在不同功能、不同时间里的数据，能否围绕同一个孩子持续连接，并真正用于下一次学习。**

因此，ToyMemory 学习个人记忆的目标不是简单保存更多学习日志，而是把分散的学习行为和结果升级成：

> **可持续更新、可解释、能真正影响下一次学习的个人学习记忆。**

---

# 二、产品目标与整体架构

ToyMemory 学习个人记忆一期建立三层理解：

| 层级 | 需要回答的问题 | 一期建设内容 |
|---|---|---|
| **基础依赖** | 这些学习数据是谁的、适配什么学习阶段 | 儿童身份、年级、学段、教材、册别 |
| **全局轻记忆** | 最近在学什么、什么时候学、最近喜欢什么 | 近期学习内容、学习时间与节律、内容偏好与兴趣 |
| **学习状态深闭环** | 具体学习对象学得怎么样、哪里需要加强 | 一期以“单词”为对象，拉通词义、拼写、发音、掌握、薄弱、复习 |

整体闭环：

**学习行为/结果 → 形成个人记忆 → 影响下一次学习 → 产生新结果 → 更新个人记忆**

一期核心模型：

> **基础依赖 + 全局轻记忆 + 单词学习状态深闭环**

---

# 三、基础依赖

## 3.1 目标

确保不同学习功能产生的数据能够正确归属到同一个孩子，并具备基本学习阶段上下文。

## 3.2 一期信息

| 信息 | 用途 |
|---|---|
| 儿童身份 | 统一不同功能中的学习数据 |
| 年级 | 内容与难度适配 |
| 学段 | 判断学习范围 |
| 教材版本 | 同步学习内容匹配 |
| 册别 | 定位当前教材进度 |
| 账号/设备关联 | 保证跨功能数据属于同一儿童 |

## 3.3 使用原则

长期档案信息以权威来源为准。

例如账号档案为“三年级”，孩子临时选择“四年级数学内容”，只记录：

> 本次学习四年级内容。

不能直接修改长期年级信息。

---

# 四、全局轻记忆

全局轻记忆主要回答三个问题：

1. 最近在学什么；
2. 通常什么时候学；
3. 最近更愿意主动接触什么内容。

这一层描述孩子近期学习上下文，不直接判断某个具体知识点是否已经掌握。

---

## 4.1 近期学习内容

### 目标

回答：

> **孩子最近主要在学什么？**

### 数据来源

覆盖现有主要学习功能：

- 查词、翻译；
- 背单词、报听写；
- 教材同步听、英语听力专项；
- 英语同步学、练口语；
- 拍英语作文；
- 数学同步学；
- 全科讲题等。

### 一期记录

| 信息 | 示例 |
|---|---|
| 学科 | 英语 |
| 学习类型 | 单词 |
| 学习任务 | 背单词 |
| 学习对象类型 | 单词 |
| 来源功能 | 背单词 |
| 时间 | 9月2日 20:15 |

### 一期输出

例如：

> 最近7天主要学习英语。  
> 最近英语学习中，单词和听力类学习较多。  
> 最近数学同步学使用增加。

这里只描述“最近在学什么”，不能因为某功能使用较多就判断对应学科薄弱。

---

## 4.2 学习时间与节律

### 目标

回答：

> **孩子通常什么时候学习，最近学习频率如何？**

### 一期输出

| 记忆 | 示例 |
|---|---|
| 常用学习时段 | 19:00—21:00 |
| 工作日主要学习时段 | 晚上 |
| 周末主要学习时段 | 上午、晚上 |
| 最近学习频率 | 最近7天有5天发生学习 |
| 最近一次学习 | 昨晚20:10 |

如果当前只能获得页面进入到退出时间，且无法排除待机、离开等情况，则只记录：

> 功能停留时长。

不直接定义为：

> 有效学习时长。

一期不根据学习时间推断自律、专注、学习态度等人物特征。

---

## 4.3 内容偏好与兴趣

### 4.3.1 目标与原则

回答：

> **孩子最近更愿意主动看什么、问什么、选择什么。**

兴趣主要用于：

- 内容推荐排序；
- 学习内容包装；
- 少量兴趣扩展；
- 提高内容接受度。

核心原则：

> **学情决定“学什么”，兴趣决定“怎么呈现”。**

ToyMemory 不直接采集“兴趣标签”，而是先采集孩子对具体内容的行为，再理解内容主题，并根据真实行为证据形成兴趣状态。

整体链路：

**有效兴趣行为 → 获取具体内容 → 大模型理解主题 → 主题标准化 → 记录儿童+主题+行为+时间 → 规则聚合 → 形成兴趣状态**

---

### 4.3.2 词典笔哪些功能可以采兴趣

判断一个功能是否适合采兴趣，核心看：

> **孩子是否具有真实的内容选择权。**

| 功能/内容 | 当前建议 | 采集内容 | 说明 |
|---|---|---|---|
| **练口语** | 一期重点 | 主动选择的话题、重复选择的话题 | 强兴趣信号 |
| **国学/内容学习** | 一期重点 | 主动选择的具体篇目、故事、人物、内容类型 | 强兴趣信号 |
| **内容收藏** | 一期重点 | 主动收藏的具体内容 | 强兴趣信号，需排除学习收藏 |
| **开放问答/主动提问** | 如现有入口支持则接入 | 孩子主动询问的内容 | 强兴趣信号 |
| **明确喜欢/不喜欢** | 如现有入口支持则接入 | 喜欢、不喜欢、不感兴趣、不再推荐 | 强正/负向信号 |
| **查词/查句** | 辅助 | 查询内容涉及的主题 | 可能来自作业，不单独形成强兴趣 |
| **翻译** | 辅助 | 主动翻译内容的主题 | 可能来自学习任务 |
| **拍英语作文** | 辅助 | 作文内容主题 | 题目可能由老师指定 |
| **教材同步听** | 条件使用 | 主动额外选择的内容 | 默认课程不算兴趣 |
| **英语听力专项** | 条件使用 | 主动选择的听力主题 | 专项任务本身不算兴趣 |
| **英语同步学** | 条件使用 | 主动选择的拓展内容 | 规定课程不算兴趣 |
| **报听写** | 不采 | — | 属于学习任务 |
| **生词本** | 不采 | — | 代表学习巩固需求 |
| **专项测试** | 不采 | — | 反映学情 |
| **复习计划** | 不采 | — | 反映学习需要 |

特别注意：

> 听写错误词收藏进入生词本，代表“需要继续学习”，不能解释成“喜欢这个词”。

---

### 4.3.3 什么行为可以成为兴趣证据

一期不需要复杂兴趣分数，但需要区分行为强弱和行为来源。

| 行为 | 兴趣证据 |
|---|---|
| 明确表达喜欢 | 很强 |
| 主动搜索 | 强 |
| 主动提问 | 强 |
| 主动收藏内容 | 强 |
| 主动选择内容/话题 | 强 |
| 跨天重复主动进入 | 强 |
| 推荐后主动点击 | 中 |
| 主动继续下一条 | 中 |
| 完整看完 | 弱 |
| 单次点击 | 弱 |
| 停留较长 | 弱 |
| 系统自动播放 | 不使用 |
| 系统默认内容 | 不使用 |
| 强制学习任务 | 不使用 |

兴趣相关事件需要尽量区分：

- 主动搜索；
- 主动选择；
- 推荐后选择；
- 系统自动；
- 默认进入；
- 任务要求。

关键原则：

> **主动行为 > 被动消费。**

---

### 4.3.4 内容没有标签时怎么处理

一期不建设完整人工内容标签体系，采用：

> **按需理解 + 主题标准化 + 结果复用。**

流程：

**某个内容第一次进入有效兴趣链路**

↓

获取标题、简介、正文、对话、音频转写或用户问题

↓

大模型输出：

- 一个主要主题；
- 最多两个相关主题。

例如：

> 《三角龙的角有什么作用》

大模型得到：

> 原始主题：三角龙 / 史前动物

↓

进入 ToyMemory 兴趣主题标准词表进行归一化：

> 标准主题：恐龙

↓

将结果与内容ID关联保存

↓

后续其他孩子再次对同一内容产生行为时，直接复用主题结果。

只有以下情况需要重新分析：

- 内容发生明显变化；
- 原主题置信度过低；
- 主题规范发生调整；
- 模型版本升级并需要重跑。

因此不是“每个孩子每次行为都调用大模型”，而是：

> **内容按需理解一次，用户兴趣持续聚合。**

### 主题标准化

一期不建设复杂兴趣图谱，只维护一个轻量的：

> **ToyMemory 兴趣主题标准词表**

例如：

- 恐龙；
- 动物；
- 植物；
- 航天；
- 足球；
- 汽车；
- 历史；
- 神话；
- 故事；
- 科普等。

如果大模型输出的新主题无法映射到现有标准主题，则先形成：

> 新主题候选

后续再决定是否纳入标准词表。

### 大模型边界

大模型负责：

> **理解内容“是什么主题”。**

产品规则负责：

> **判断这个主题对孩子来说有多确定。**

即：

> **大模型负责“理解是什么”，规则负责“判断有多确定”。**

大模型不得直接推断：

- 孩子性格；
- 能力水平；
- 价值观；
- 职业倾向；
- 深层动机。

---

### 4.3.5 兴趣如何形成和使用

兴趣状态由产品规则根据真实行为证据形成。

一期建议先使用简单、可配置的规则。

| 状态 | 一期建议规则 |
|---|---|
| **兴趣候选** | 近7天至少出现1次强主动兴趣行为 |
| **近期兴趣** | 近7天出现≥3次强主动行为，且跨≥2天、涉及≥2个不同内容 |
| **兴趣冷却** | 曾形成近期兴趣，但近30天没有新的强主动行为 |
| **明确不感兴趣** | 用户明确表达不喜欢/不再推荐，立即停止相关兴趣使用 |

以上阈值建议作为可配置参数，不写死在代码中。

这里使用“兴趣冷却”，而不是“兴趣下降”，因为：

> **没有行为不等于兴趣真的下降，也可能只是近期没有接触相关内容。**

例如最近7天：

- 主动搜索“霸王龙为什么灭绝”；
- 主动选择“三角龙有什么特点”；
- 收藏“恐龙百科”；
- 主动提问“世界上最大的恐龙是什么”。

大模型分别理解内容主题，系统规则聚合后形成：

> **近期兴趣：恐龙**

如果只有一次动物相关主动行为，则只形成：

> **兴趣候选：动物**

兴趣的使用包括：

- 恐龙相关内容适当提高推荐顺序；
- 有合适学习内容时，用恐龙主题进行学习包装；
- 可少量探索“古生物、化石、史前动物”等邻近主题。

扩展主题不能直接写入孩子兴趣，只有孩子后续真正产生主动行为后，才能形成新的兴趣证据。

# 五、学习状态深闭环：一期以单词验证

一期只选择：

> **单词**

作为第一种深度学习记忆对象。

当前一个单词已经可以横跨：

**报听写 → 生词本 → 背单词 → 专项测试 → 发音评测 → 英语作文 → 复习计划**

能够同时验证：

- 熟悉度；
- 词义；
- 拼写；
- 发音；
- 掌握状态；
- 薄弱问题；
- 长期复习。

---

# 六、单词个人记忆模型

ToyMemory围绕：

> **儿童 + 单词**

持续汇聚不同学习场景中的结果。

| 记忆维度 | 结果 | 主要来源 |
|---|---|---|
| 主观熟悉度 | 认识 / 模糊 / 不认识 | 背单词 |
| 英→中词义 | 正确 / 错误 | 英文选义 |
| 中→英提取 | 正确 / 错误 | 中文选词 |
| 专项拼写 | 正确 / 错误 | 填空拼写 |
| 听写拼写 | 用户主动标记错误 | 报听写 |
| 真实写作拼写 | 拼写检查结果 | 拍英语作文 |
| 发音准确度 | 评测结果 | 发音评测 |
| 发音流畅度 | 评测结果 | 发音评测 |
| 发音完整度 | 评测结果 | 发音评测 |
| 发音标准度 | 评测结果 | 发音评测 |
| 发音问题 | 发音指导 | 发音评测 |
| 当前学习状态 | 未学习 / 学习中 / 已掌握 | 背单词 |
| 待巩固状态 | 是否进入生词本 | 生词本 |
| 复习状态 | 计划 / 执行 / 结果 | 背单词 |
| 最近学习时间 | 最近一次有效学习时间 | ToyMemory聚合 |
| 当前主要问题 | 如“拼写需要重点巩固” | ToyMemory聚合 |
| 下一步学习动作 | 如“优先拼写复习” | 根据当前记忆实时生成 |

例如 `environment`：

> 当前状态：学习中  
> 主观熟悉度：模糊  
> 英→中：正确  
> 中→英：正确  
> 专项拼写：错误  
> 听写：曾被标错  
> 作文：曾出现拼写错误  
> 生词本：已加入  
> 发音：有四维评测及发音指导  
> 复习：待复习  
> 当前主要问题：拼写需要重点巩固  
> 下一步学习动作：优先拼写复习，并继续发音巩固

ToyMemory最终需要回答：

> **这个词现在处于什么状态、具体哪里还有问题、下一步应该做什么。**

# 七、单词记忆判断规则

## 7.1 复用现有主学习状态

背单词已有：

> 未学习 / 学习中 / 已掌握

一期直接复用，不重新建设第二套掌握度算法。

ToyMemory负责汇聚跨功能证据和历史变化，不自行替代背单词现有主状态。

## 7.2 主状态与分项表现分开

例如：

> 当前状态：学习中  
> 词义正常  
> 拼写较弱  
> 发音正在改善

避免简单压缩为：

> 会 / 不会。

## 7.3 单次错误只记录事实

例如一次作文拼错，只记录：

> 本次真实写作出现拼写错误。

不直接形成长期拼写薄弱。

## 7.4 报听写只提供确定的错误证据

当前报听写由用户主动标记错误词，因此：

### 用户主动标错

可以记录：

> 本次听写错误。

### 用户没有标错

只能表示：

> 本次没有收到错误标记。

不能自动推断：

> 本次听写正确。

因此：

> **报听写未标错 ≠ 正确证据。**

只有产品后续具备逐词自动判定结果时，才可以把明确的“正确”作为正向学习结果。

## 7.5 多场景重复问题提高巩固优先级

如果同一个词出现：

- 填空拼写错误；
- 报听写又被标错；
- 作文再次拼错；

可以形成：

> **该单词拼写需要重点巩固。**

判断始终落到：

> **具体单词 + 具体问题。**

不能进一步写成：

> 孩子拼写能力差。

## 7.6 保留学习变化

例如某单词发音标准度：

> 72 → 81 → 89

ToyMemory应该知道：

> 该词发音表现正在改善。

因此不仅保存最近一次结果，也需要保留关键历史变化。

## 7.7 已掌握后出现新问题不直接推翻主状态

如果背单词状态已经“已掌握”，后来作文中再次拼错一次：

先增加新的错误事实，不直接把主状态改成“未掌握”。

如果后续持续出现相同问题，再提高重新巩固优先级。

# 八、复习与长期保持

当前产品已经存在：

**报听写错误 → 收藏进入生词本 → 再次听写/从生词本背单词 → 继续学习 → 复习计划 → 后续复习**

因此一期不重新建设复习产品。

ToyMemory需要汇聚：

| 信息 | 作用 |
|---|---|
| 生词本状态 | 判断是否需要继续学习 |
| 复习计划 | 知道哪个词什么时候复习 |
| 计划执行 | 是否进行了复习 |
| 复习结果 | 本次复习表现 |
| 后续状态 | 判断是否改善 |
| 再次出现问题 | 判断是否需要重新巩固 |

形成：

> **发现问题 → 再学习 → 复习 → 新结果 → 更新记忆**

# 九、记忆如何影响下一次学习

一期不仅要证明“能记住”，还要证明：

> **记忆能够真正被产品消费。**

| 记忆 | 主要作用 |
|---|---|
| 近期学习内容 | 决定下一次优先承接什么学习方向 |
| 学习时间与节律 | 决定什么时间更适合出现学习内容 |
| 内容兴趣 | 决定内容包装、排序和少量兴趣扩展 |
| 单词当前状态 | 决定哪些词还需要继续学习 |
| 单词具体问题 | 决定重点练词义、拼写还是发音 |
| 复习计划 | 决定哪些词当前应该重新出现 |

例如：

> 最近主要学习英语；  
> 通常晚上19:00—21:00学习；  
> 最近对恐龙主题兴趣较高；  
> environment 拼写多次出现问题，并且已经到复习时间。

后续可以：

> **在常用学习时段优先承接 environment 的拼写复习，在有适合内容时使用恐龙主题进行包装。**

## 9.1 一期必须明确至少一个真实消费出口

ToyMemory 一期不能只完成“记忆生成”，至少要选择一个真实产品入口消费记忆结果。

建议优先验证以下出口之一：

| 记忆 | 可验证出口 |
|---|---|
| 单词学习状态 | 背单词/复习场景决定优先练哪个词 |
| 单词具体问题 | 决定优先进入词义、拼写或发音练习 |
| 复习计划 | 到期时优先承接对应单词复习 |
| 内容兴趣 | 推荐内容排序或学习内容包装 |
| 学习节律 | 后续承接或提醒的触发时段 |

一期验收要求：

> **至少有一个真实产品入口根据 ToyMemory 结果产生不同的学习行为或内容承接。**

否则只能证明“能生成记忆”，不能证明“记忆真正有用”。

# 十、一期数据与产品改造要求

一期优先复用现有产品能力，不为记忆体系大规模重做埋点；但对无法形成个人记忆的关键字段，需要针对性补充。

需要特别区分：

> **产品已经有这个功能**

和

> **ToyMemory 已经能够拿到可用数据**

这两件事不能等同。

状态说明：

- ✅ 产品能力已具备
- 🟡 ToyMemory数据可用性待确认/需补关联
- 🔴 关键缺口，需要新增或打通
- ⚪ 一期不做

| 模块 | 产品能力现状 | ToyMemory数据现状 | 一期处理 |
|---|---|---|---|
| 儿童身份、年级、教材、册别 | ✅ 已有相关能力 | 🟡 权威来源及跨功能归属待确认 | 确认权威来源和统一儿童标识 |
| 近期学习行为 | ✅ 各功能均有使用行为 | 🟡 学科/类型映射需统一 | 统一学科、学习类型、时间 |

| 练口语话题 | ✅ 已有功能 | 🟡 是否能拿到具体主动话题待确认 | 接入具体话题及来源 |

| 跨功能单词统一 | 各功能均涉及单词 | 🔴/🟡 是否存在统一单词ID待确认 | 一期必须确认并打通 |
| 跨功能儿童统一 | 各功能均有用户行为 | 🔴/🟡 是否存在统一儿童ID待确认 | 一期必须确认并打通 |
| 记忆消费出口 | 现有产品已有学习入口 | 🔴 需明确具体消费方式 | 一期至少接入一个真实入口 |

> **同一个孩子能不能跨功能识别？**

> **ToyMemory生成的记忆最终在哪个真实产品入口被使用？**

# 十一、一期范围与验收

## 11.1 一期范围总表

| 模块 | 一期做什么 | 核心依赖 | 优先级 |
|---|---|---|---|
| **基础依赖** | 儿童身份、年级、教材统一 | 账号/档案体系 | P0 |
| **近期学习** | 学科、学习类型、最近学习方向 | 功能行为事件 | P0 |
| **学习节律** | 常用时段、频率、最近学习时间 | 时间事件 | P1 |
| **内容兴趣** | 主动内容行为 + 大模型主题理解 + 标准主题归一 + 兴趣状态 | 内容对象、行为来源 | P1 |
| **单词深闭环** | 熟悉度、词义、拼写、发音、状态、复习 | 儿童ID、单词ID、结果数据 | P0 |
| **记忆消费** | 至少一个真实入口使用ToyMemory结果 | 推荐/学习入口 | P0 |

### 兴趣一期重点

优先接：

- 练口语主动话题；
- 国学/内容主动选择；
- 内容收藏。

如现有产品已有入口，再接：

- 主动问答；
- 明确喜欢/不喜欢。

查词、翻译、作文、教材同步听、英语听力专项、英语同步学只作为辅助兴趣证据。

### 一期暂不建设

- 完整数学知识点掌握体系；
- 句子级长期记忆；
- 完整听说读写能力画像；
- 完整口语能力等级；
- 人工完整内容标签体系；
- 复杂兴趣知识图谱；
- 复杂遗忘曲线；
- 新的单词掌握度算法；
- 自律、专注等人格判断；
- 单次行为形成长期兴趣；
- 单次错误形成长期薄弱。

## 11.2 验收

### A. 基础依赖

验证：

- 不同学习功能的数据能够归属同一儿童；
- 年级、教材等基础信息来源稳定；
- 临时学习设置不会覆盖长期基础信息。

### B. 全局轻记忆

真实使用后能够形成：

> 最近7天主要学习英语，单词和听力类学习较多。  
> 最近主要在晚上19:00—21:00学习。

兴趣验证：

1. 孩子对多个恐龙相关内容产生主动行为；
2. 大模型能够理解不同内容的主题；
3. 相近主题可以归一到标准主题“恐龙”；
4. 系统能够区分主动选择和系统自动行为；
5. 达到规则阈值后形成“近期兴趣：恐龙”；
6. 单次强行为只能形成“兴趣候选”；
7. 30天没有新强行为时进入“兴趣冷却”，而不是直接判断“不喜欢”；
8. 明确拒绝后能够停止对应兴趣使用；
9. 每个兴趣结论都可以回溯到真实行为证据。

### C. 单词深闭环

选择一个测试单词，例如：

> `environment`

完成：

**报听写标错 → 加入生词本 → 从生词本进入背单词 → 选择模糊 → 完成英文选义/中文选词/填空拼写 → 完成单词发音评测 → 英语作文检查真实拼写 → 获取当前学习状态 → 生成复习计划 → 完成后续复习 → ToyMemory更新最新学习记忆**

最终 ToyMemory 能够输出：

> 当前状态：学习中  
> 词义：基本稳定  
> 拼写：需要重点巩固  
> 发音：存在具体改善方向  
> 复习：已到期/待复习  
> 下一步：优先进行拼写复习

要求：

- 识别同一个儿童；
- 识别同一个单词；
- 汇聚跨功能学习结果；
- 获取当前最新状态；
- 保留关键历史变化；
- 区分词义、拼写、发音等具体问题；
- 报听写未标错不能自动记为正确；
- 获取复习计划和结果；
- 根据后续结果更新记忆。

### D. 记忆消费验收

一期至少选择一个真实入口进行验证，例如：

> ToyMemory 判断 `environment` 当前主要问题为拼写，且已经到复习时间。

产品下一次承接时：

> 优先进入 `environment` 的拼写复习，而不是再次进行词义识别。

要求能够证明：

> **如果没有这条记忆，产品不会做出完全相同的承接选择；记忆确实改变了下一次学习。**

# 十二、后续扩展

一期验证成功后，再逐步扩大标准学习对象。

### 第二阶段：句子

利用现有句子跟读评测，形成：

> 句子级朗读和发音长期记忆。

### 第三阶段：知识点

扩展到：

- 数学知识点；
- 英语语法；
- 错题；
- 同类题；
- 迁移题。

形成：

> 知识点掌握、薄弱与复习记忆。

### 第四阶段：技能

逐步形成：

- 听；
- 说；
- 读；
- 写；
- 词汇；
- 语法；
- 计算；
- 推理等长期变化。

兴趣侧根据一期真实效果，再决定是否建设更复杂的主题关系和兴趣扩展体系。
