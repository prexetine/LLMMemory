## 2. 首次运行

### 2.1 准备凭证

```powershell
cd <仓库根>
copy config.example.yaml config.yaml
# 编辑 config.yaml，填入真实 api_key 与推理接入点 ID(ep-xxxx)
```

`config.yaml` 已被 `.gitignore` 忽略，**提交前确认**。

### 2.2 准备数据

运行需要以下目录结构（`data_root` 指向它）：

```
<data_root>/
  users.csv                         # 或 core_50_provisional.csv
  candidate_data/
    <device_id>/
      dialogue.jsonl.gz             # 必需：对话数据
      photo.jsonl.gz                # 可选：photos.enabled=true 时需要
```

从 `core_users/` 找出目标用户的 `device_id`（形如 `12354838B66792A5`），
必须与 `users.csv` 中的条目一致，否则启动即报「设备不在当前数据目录的用户名单中」。

### 2.3 先跑 prepare（不调用模型）

**强烈建议第一次先跑 `prepare`**：它只校验数据、106 维映射和容量预算，**不产生任何模型费用**。

```powershell
& 'D:\envrionment\Python312\python.exe' -X utf8 `
  'python_app\src\memory_agent.py' --config 'python_app\config\memory_agent_generic_flow.json' --mode prepare
```

### 2.4 再跑 live（真实调用）

```powershell
& 'D:\envrionment\Python312\python.exe' -X utf8 `
  'python_app\src\memory_agent.py' --config 'python_app\config\memory_agent_core_top5_0907_latest.json' --mode live
```

> **费用提醒**：`live` 会产生真实 API 计费。当前配置未设 `max_calls`（无上限）。
> 首次验证建议先用 `max_sessions: 1` + `user_selection.device_ids` 限一个用户。

### 2.5 续跑

```powershell
# 末尾加 --resume
... --mode live --resume
```

`--resume` 的约束（源码强制）：

- **只能用于 `live`**，`prepare` + `--resume` 会报错；
- 输出目录必须存在 `batch_manifest.json`，否则报「缺少 batch_manifest.json，无法安全续跑」；
- 会校验 `device_id` / `input_hash` / `context_config_hash` / `review_version` 与首次运行**一致**；
- **不能跨流程版本续跑**（`generic-flow-v2` 与 `generic-flow-v3-relations` 不可互续），换版本请用新输出目录。

## 5. 状态语义（重要 —— 别把技术失败当业务结论）

| 状态 | 含义 | 要不要处理 |
| --- | --- | --- |
| `completed` | 全部 Session 已提交 | — |
| `partial` / `awaiting_retry` | 有 Session 未提交，**可安全续跑** | 加 `--resume` 重跑 |
| `failed` | 有 Session 异常隔离后仍失败 | 看 `session_failures.jsonl` |
| `interrupted` | 用户 Ctrl+C | 加 `--resume` |
| `pending`（候选级） | **语义待确认**，不是技术失败 | 人工复核，别当 bug |
| `discarded`（候选级） | 保存去向判定为「无长期价值」 | 正常，非错误 |

> 退出码：`0` = 全部完成；`2` = 存在失败或部分完成。

## 6. 中断与并发

- **Ctrl+C**：主进程停止派发新用户，**在途子进程跑到下一个模型调用检查点才退出**。
  提示「请勿强制关闭窗口」时**不要强杀**，否则当前 Session 可能留下未提交状态（仍可用 `--resume` 恢复）。
- **批次锁**：同一输出目录**禁止并发运行**，第二个进程会拒绝启动。
  崩溃后 `.batch.lock` 文件会残留，但**锁已释放**，可直接重启。
- **并行度**：`parallel_users` 最大 3，且**同一用户内部严格串行**。

## 7. 常见故障排查

| 症状 | 原因 | 处理 |
| --- | --- | --- |
| `FileNotFoundError: config.yaml` | 未创建凭证文件 | 从 `config.example.yaml` 复制 |
| `KeyError` 在 `model_map` | `model_alias` 不在 `config.yaml` | 核对 alias 拼写与 `model_map` 的 key |
| `服务地址不符合授权服务白名单` | `base_url` 被改 | 只允许官方两个域名（源码硬校验） |
| `不允许调用其他模型` | `model_alias` 不以 `doubao-`/`deepseek-` 开头 | 改回允许值 |
| `设备不在当前数据目录的用户名单中` | `device_id` 与 `users.csv` 不一致 | 核对名单文件 |
| `此批次目录正在被另一进程使用` | 有并发进程 | 等对方结束，或换输出目录 |
| `批次输出目录非空，请换新目录或显式--resume` | 目录已有产物 | 换目录或加 `--resume` |
| `缺少batch_manifest.json，无法安全续跑` | 目录不是首次运行的产物 | 用新目录首次运行 |
| `运行流程版本不一致，禁止跨流程续写` | 改了 `flow_version` 后续跑 | 换新输出目录重跑 |
| `旧版或未知flow_version已停止执行` | 配置是旧版本值 | 改为 `generic-flow-v2` 或 `-v3-relations` |
| `新流程不接受旧控制参数：xxx` | 配置残留旧字段 | 删除 §3.5 列出的字段 |
| `规则必须恰好覆盖106项` | `rules_file` 被改动 | 恢复原始 106 维 MD |
| `BGE健康检查失败` / `本地编码服务不可用` | 未启动 BGE 或端口占用 | 检查 `retrieval.service_config` 与端口 8766 |
| 有 `session_failures.jsonl` | Session 级异常 | 看文件内 `code`/`reason`，`--resume` 重跑 |
| `TimeoutError` | 单次请求超时（60s） | 调大 `timeout_seconds`，注意无自动网络重试 |

## 8. 随包数据说明

`data/1017/` 是从原始 xlsx 导出中**筛好的可用数据**（13 个用户，7.65 MB），
让接手人不必处理 718.7 MB 原始表格即可直接开跑。**完整说明见仓库根级 `DATA.md`**，此处只列要点。

### 这批数据是什么

原始导出（`智能体对话全部数据20261014.xlsx` 等 4 个 xlsx，共 718.7 MB）→
筛出 13 个目标用户（5 core + 8 seed）→ 转成 `dialogue/photo/call/location.jsonl.gz`。

| 项 | 值 |
| --- | --- |
| 有效对话轮 | 22,755 |
| 对话 Session | 1,623 |
| 有效图片 | 1,348 |
| 数据日期 | 导出 2026-10-14 / 10-15 |

### 配套配置

`python_app/config/memory_agent_batch13_1017.json` 已把 `data_root` 指向 `data/1017`、列出 13 个用户，**可直接用**。

### ⚠️ 三个稀疏用户

`...8EBC` 与 `...8EC0` 的**对话有效轮为 0**（只有图片，会产出图片 Session）；
`...8EB9` 只有 9 有效轮 / 6 个 Session，样本量过小，统计结论不可用。
原因与明细见 `DATA.md` §3。

### 建议的第一件事

先跑 `prepare`（零费用）：

```powershell
& 'D:\envrionment\Python312\python.exe' -X utf8 `
  'python_app\src\memory_agent.py' `
  --config 'python_app\config\memory_agent_batch13_1017.json' --mode prepare
```

确认 13 个用户都返回 `prepared_not_extracted` 且 `dimensions: 106` 后，再考虑跑 `live`。

> 本目录已实测通过：13 用户全部 `exit_code=0`，共 2,890 个 Session。
