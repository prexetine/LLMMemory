如何阅读这份报告

同一批结果，两种视图

正式记忆版只展示当前正式库中有审核凭证的记忆；汇报版再补充当前运行报告中的候选、逐条Review结论及未完成窗口。两版不重新提取、不改写审核结果，也不改变数据库。

本报告不复制旧汇报版的独立分析结论。当前生产链路只有对话来源；通话、定位和照片不计入本批结果。

字段 / 状态含义与边界
已审核入库当前正式memory_id，带有效机器Review凭证。重复强化合并到同一条记忆；不是人工核实的事实。
已提取未确认尚未入库的候选：Review为defer、revise，或没有完成逐条审核。窗口审核认可不能代替最终入库。原候选与修订候选按不同版本展示，不自动猜测替代关系。
审核不通过最新逐条Review为reject；没有逐条Review时，取覆盖审核的明确拒绝。并非“用户没有这个属性”。
主体 / 场景范围候选归属的人及适用时间、场景；不能把游戏角色直接视为现实用户。
证据 / 审核原因原文引文与证据ID，以及模型实际返回的审核说明。待处理会话的证据可能只有引用ID，缺失来源字段不补造。
受限内容候选的隐私检查未通过或不确定时，汇报文件不嵌入其正文、关键词及原话。这里不是人工隐私审计，请勿公开传播。
数量口径正式记忆按memory_id统计；未入库候选按session_id＋candidate_id统计，包含修订版本。三类相加是展示条目数，不是去重事实总量、提取准确率或召回率。
会话进度已提交数来自正式数据库。一个已完成会话仍可含被拒绝或待确认的候选；这些候选没有自动转成正式记忆。
内部产品／研发汇报使用。文件包含用户标识与部分原话；受限候选已最小化展示，但不代表整份文件已做人工脱敏审查。
